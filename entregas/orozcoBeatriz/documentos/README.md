# Pequeña explicación

He creado dos diagramas de objetos a partir del modelo de clases de gestión de bases de datos: uno del caso **Inditex** y otro de un **hospital**. Se muestran las relaciones entre las clases principales (**Usuario**, **Rol**, **Permiso**, **Esquema**, **Tabla** y **Consulta**) aplicadas a situaciones reales.

Y me gustaría recalcar, por si se ha podido malentender, que en mi examen, el **Esquema** representa la **definición individual de cada tabla**, no el conjunto completo. Es como el `CREATE TABLE` de SQL o el `Schema` de Mongoose en MongoDB: cada tabla tiene su propio esquema con sus campos y reglas.
